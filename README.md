# Automatic Road Lane Detection

## Project Description

Automatic Road Lane Detection is a Computer Vision project that detects road lane markings in images and videos using Python and OpenCV.

The project uses image processing techniques such as grayscale conversion, Gaussian Blur, Canny Edge Detection, Region of Interest (ROI), and Hough Line Transform to identify lane lines.

## Features

- Detects road lanes from images
- Supports road videos
- Uses OpenCV for image processing
- Uses Canny Edge Detection
- Uses Hough Line Transform
- Uses Region of Interest masking
- Processes video frame by frame
- Saves the detected lane output

## Technologies Used

- Python
- OpenCV
- NumPy

## Requirements

- Python 3.x
- OpenCV
- NumPy
